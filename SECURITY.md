# Security

Please do not open a public issue for a security problem. Use GitHub's private vulnerability reporting
(Security tab, "Report a vulnerability") or contact the maintainer directly.

Things worth reporting: a way to read the helper's token from the device or the helper, a way to make the
device install an update from another host, a way to reach the helper without the token.

Never paste a real token, Wi-Fi password or helper address into an issue or a pull request.
